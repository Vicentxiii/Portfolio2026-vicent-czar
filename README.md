# Vicente Czar — Digital Craftsman

Personal portfolio of **Vicente Czar**, Senior Full Stack Engineer, UX Architect, and Luxury Brand Builder at Transcent Digital.

The portfolio presents selected digital products, engineering services, and Vicente's approach to building high-performance, conversion-focused experiences.

## Featured Work

- **SV ÚNICO** — A real-time supercar configurator with more than 50,000 possible combinations.
- **Rings Luxury** — Bespoke e-commerce for the Jorge Uquillas high-jewelry atelier.
- **Fernando Quincas** — A digital gallery for sculpture and mineral art.
- **Silvia Helena Corretora** — A luxury real estate website with a dedicated administration panel.

## Technology

- Vue 3 and TypeScript
- Vite
- Tailwind CSS 4
- GSAP
- Lenis

## Run Locally

Requires Node.js 20 or later.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The generated site is written to `dist/`. For Vercel, use `npm run build` as the build command and `dist` as the output directory.
